# Reference material (development only)

These files are **not served by the website** (Cloudflare serves only `public/`). Nothing in `public/` may link to this folder; `package.py` checks that.

They are earlier drafts and reference art kept so future sessions can see them. They are **not canon**: where they disagree with the current story plan, the plan wins.
